## 📋 Introducción

**Grafana** es el motor visual encargado de transformar las métricas crudas almacenadas en Prometheus en paneles gráficos, tablas y cuadros de mando interactivos de alto rendimiento.

En esta unidad instalaremos la edición **Grafana OSS** (*Open Source Software*) a través del repositorio APT oficial de Grafana Labs, asegurando actualizaciones y estabilidad continua en Debian / Ubuntu.

---

## 1. Procedimiento de Instalación en Debian / Ubuntu

### Paso 1: Instalación de dependencias previas

Nos aseguramos de que el sistema cuenta con las utilidades necesarias para gestionar repositorios seguros HTTPS y claves criptográficas:

```bash
sudo apt update
sudo apt install -y apt-transport-https software-properties-common wget gpg
```

---

### Paso 2: Importar la clave GPG del repositorio oficial

Creamos el directorio seguro para los llaveros de APT (si no existe) y descargamos la clave pública oficial de Grafana Labs:

```bash
# Crear directorio de claves APT
sudo mkdir -p /etc/apt/keyrings/

# Descargar y convertir la clave GPG oficial
wget -q -O - https://apt.grafana.com/gpg.key | gpg --dearmor | sudo tee /etc/apt/keyrings/grafana.gpg > /dev/null
```

---

### Paso 3: Añadir el repositorio oficial estable de Grafana

Añadimos la línea del repositorio apuntando a la clave descargada:

```bash
echo "deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list
```

---

### Paso 4: Instalar Grafana OSS

Actualizamos la lista de paquetes para indexar el nuevo repositorio e instalamos el paquete `grafana`:

```bash
sudo apt update
sudo apt install -y grafana
```

Verificamos la versión instalada:

```bash
grafana-server -v
```

---

## 2. Gestión del Servicio con Systemd

Grafana incluye por defecto la unidad de servicio `grafana-server.service`. Para habilitarla al arranque e iniciarla inmediatamente:

```bash
# Recargar systemd
sudo systemctl daemon-reload

# Habilitar e iniciar el servicio grafana-server
sudo systemctl enable --now grafana-server

# Verificar el estado del servicio
sudo systemctl status grafana-server
```

### Comprobación del puerto de red `3000`:
Verificamos que el servidor está escuchando en el puerto TCP `3000`:

```bash
ss -plunt | grep 3000
```
Salida esperada:
```text
tcp   LISTEN 0      4096         *:3000            *:*    users:(("grafana",pid=14520,fd=12))
```

---

## 3. Primer Acceso y Configuración Inicial

### 🌐 Conexión vía navegador
Abre tu navegador web y dirígete a:

```text
http://localhost:3000   (o http://<IP_DE_TU_SERVIDOR>:3000)
```

### 🔑 Credenciales predeterminadas:
- **Usuario:** `admin`
- **Contraseña:** `admin`

<p align="center">
  <b>Pantalla de inicio de sesión de Grafana:</b><br/>
  <i>(Introduce admin / admin en el primer acceso)</i>
</p>

### 🔒 Cambio forzoso de contraseña
En el primer inicio de sesión, Grafana solicitará obligatoriamente cambiar la contraseña por defecto. Establece una contraseña robusta (por ejemplo, `AdminSeguro2026!`).

---

## 4. Archivo de Configuración Principal (`grafana.ini`)

El comportamiento global de Grafana se define en el archivo `/etc/grafana/grafana.ini`.

```bash
sudo nano /etc/grafana/grafana.ini
```

### Parámetros más relevantes:
- **`[server] http_port = 3000`**: Puerto TCP donde escucha la interfaz web.
- **`[server] domain = localhost`**: Nombre de dominio asignado al servidor.
- **`[security] admin_user = admin`**: Nombre del usuario administrador principal.
- **`[smtp]`**: Parámetros de servidor de correo para envío de alertas (se configurará en el Tema 7).

> [!NOTE]
> Cualquier modificación en `/etc/grafana/grafana.ini` requiere reiniciar el demonio para surtir efecto:
> ```bash
> sudo systemctl restart grafana-server
> ```
