## 📋 Introducción

Prometheus es una aplicación escrita en **Go** que se distribuye como un binario único autocontenido, lo que facilita enormemente su despliegue y mantenimiento en sistemas GNU/Linux.

En esta unidad detallamos el procedimiento estándar de instalación mediante **binarios oficiales** (el recomendado en entornos profesionales para contar con la versión más reciente) y la alternativa mediante el gestor de paquetes **APT**.

---

## 1. Método Recomendado: Instalación mediante Binarios Oficiales

### Paso 1: Creación del usuario y directorios del sistema

Por motivos de seguridad, Prometheus nunca debe ejecutarse como usuario `root`. Creamos un usuario de sistema dedicado sin directorio personal ni acceso a shell interactiva:

```bash
# Crear grupo y usuario de sistema sin inicio de sesión
sudo groupadd --system prometheus
sudo useradd -s /sbin/nologin --system -g prometheus prometheus

# Crear directorios para configuración y base de datos TSDB
sudo mkdir -p /etc/prometheus
sudo mkdir -p /var/lib/prometheus
```

---

### Paso 2: Descarga y descompresión de Prometheus

Accedemos al directorio temporal y descargamos la versión estable más reciente desde el repositorio oficial de GitHub de Prometheus:

```bash
cd /tmp
# Descargar el tarball oficial para arquitectura AMD64
wget https://github.com/prometheus/prometheus/releases/download/v2.51.2/prometheus-2.51.2.linux-amd64.tar.gz

# Descomprimir el archivo
tar -xvzf prometheus-2.51.2.linux-amd64.tar.gz
cd prometheus-2.51.2.linux-amd64
```

---

### Paso 3: Instalación de binarios y bibliotecas de consola

Movemos los ejecutables al directorio estándar `/usr/local/bin/` y las librerías a `/etc/prometheus`:

```bash
# Copiar binarios principales
sudo cp prometheus /usr/local/bin/
sudo cp promtool /usr/local/bin/

# Copiar bibliotecas de consolas web clásicas
sudo cp -r consoles /etc/prometheus/
sudo cp -r console_libraries /etc/prometheus/
```

Verificamos que los ejecutables son reconocidos:

```bash
prometheus --version
promtool --version
```

---

### Paso 4: Creación del archivo de configuración `prometheus.yml`

Creamos el archivo de configuración principal en `/etc/prometheus/prometheus.yml`:

```bash
sudo nano /etc/prometheus/prometheus.yml
```

Añadimos la siguiente configuración base:

```yaml
# Configuración global
global:
  scrape_interval: 15s     # Frecuencia con la que se consultan los endpoints
  evaluation_interval: 15s # Frecuencia con la que se evalúan las reglas de alerta

# Configuración de los jobs de recolección (Scraping)
scrape_configs:
  # Monitorización del propio servidor Prometheus
  - job_name: "prometheus"
    static_configs:
      - targets: ["localhost:9090"]
```

Ajustamos los permisos para que pertenezcan al usuario `prometheus`:

```bash
sudo chown -R prometheus:prometheus /etc/prometheus
sudo chown -R prometheus:prometheus /var/lib/prometheus
sudo chmod -R 775 /etc/prometheus
sudo chmod -R 775 /var/lib/prometheus
```

> [!TIP]
> Puedes validar la sintaxis del archivo de configuración antes de arrancar el servicio usando la herramienta oficial `promtool`:
> ```bash
> promtool check config /etc/prometheus/prometheus.yml
> # Salida esperada: SUCCESS: /etc/prometheus/prometheus.yml is valid prometheus config file syntax
> ```

---

### Paso 5: Creación del servicio Systemd

Para gestionar Prometheus como un servicio en segundo plano que se inicie automáticamente con el sistema operativo, creamos la unidad de servicio:

```bash
sudo nano /etc/systemd/system/prometheus.service
```

Insertamos la siguiente definición:

```ini
[Unit]
Description=Prometheus Time Series Collection and Alerting Server
Wants=network-online.target
After=network-online.target

[Service]
User=prometheus
Group=prometheus
Type=simple
ExecStart=/usr/local/bin/prometheus \
    --config.file=/etc/prometheus/prometheus.yml \
    --storage.tsdb.path=/var/lib/prometheus/ \
    --web.console.templates=/etc/prometheus/consoles \
    --web.console.libraries=/etc/prometheus/console_libraries \
    --web.listen-address=0.0.0.0:9090 \
    --web.enable-lifecycle

Restart=always

[Install]
WantedBy=multi-user.target
```

> [!NOTE]
> El flag `--web.enable-lifecycle` permite recargar la configuración de Prometheus en caliente sin reiniciar el servicio mediante una llamada HTTP:
> `curl -X POST http://localhost:9090/-/reload`

---

### Paso 6: Inicio y habilitación del servicio

```bash
# Recargar systemd para detectar el nuevo servicio
sudo systemctl daemon-reload

# Habilitar e iniciar Prometheus
sudo systemctl enable --now prometheus

# Comprobar el estado del servicio
sudo systemctl status prometheus
```

---

## 2. Método Alternativo: Instalación rápida vía APT

En sistemas Debian y Ubuntu, Prometheus también se encuentra en los repositorios oficiales de la distribución:

```bash
sudo apt update
sudo apt install -y prometheus
```

- **Ventaja:** Instalación en un único comando y servicio systemd configurado automáticamente.
- **Desventaja:** Las versiones de los repositorios de la distribución suelen estar varios meses por detrás de la versión oficial más reciente.

## 3. Comprobación y Verificación

### 1. Comprobación del puerto 9090
Verificamos que el puerto `9090` está en estado `LISTEN`:

```bash
ss -plunt | grep 9090
```
Salida esperada:
```text
tcp   LISTEN 0      4096         *:9090            *:*    users:(("prometheus",pid=12345,fd=7))
```

### 2. Acceso a la Interfaz Web de Prometheus
Abre tu navegador web e ingresa a:

```text
http://localhost:9090  (o http://<IP_DE_TU_SERVIDOR>:9090)
```

En la barra superior de navegación dispones de:
- **`Graph` / `Table`:** Consola para ejecutar consultas PromQL en vivo y visualizar gráficos interactivos.
- **`Status` $\rightarrow$ `Targets`:** Lista de todos los endpoints configurados con su estado (`UP` o `DOWN`), último scrape y duración.
- **`Status` $\rightarrow$ `Configuration`:** Muestra el archivo `prometheus.yml` activo cargado en memoria.

#### Consulta de prueba inicial:
En el buscador de la pestaña `Graph`, escribe:
```promql
up
```
Pulsa el botón **Execute**. Deberás ver la métrica con valor `1`, confirmando que el propio Prometheus se está scrapeando con éxito.
